# Evidence index

The evidence set records reproducible system facts rather than screenshots alone.

- `RUN_RESULTS.md`: row counts, data-quality results, analytical answers, performance comparison and successful job run details
- `DATABRICKS_RESOURCES.md`: direct workspace links and resource identifiers
- Jira attachments: visual pipeline graph, run status and notebook/pipeline source files

Screenshots support the recorded identifiers, while the repository and runbook are the primary reproducibility evidence.
